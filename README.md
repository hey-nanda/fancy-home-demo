# Fancy Home — Demo

Versão demonstrativa de um E-commerce de decoração e artigos para casa, desenvolvido como projeto de portfólio com foco em **design de interface, experiência do usuário e desenvolvimento front-end**.

Esta versão é uma demonstração navegável da loja, sem necessidade de servidor ou banco de dados.

## Funcionalidades

- Catálogo de produtos com pesquisa, filtros e ordenação;
- Páginas individuais de produtos;
- Lista de favoritos e sacola com armazenamento local (`localStorage`);
- Simulação visual do checkout;
- Layout responsivo.

## Tecnologias

**HTML, CSS, JavaScript e JSON.** Os produtos são carregados de um catálogo estático; favoritos e sacola ficam salvos apenas no navegador utilizado.

## Executar localmente

Abra o projeto com um servidor estático, como a extensão **Live Server** do VS Code, e acesse `index.html`.

## Publicar no GitHub Pages

1. Envie os arquivos para a branch `main` do repositório.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`.
3. Acesse `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

Todos os caminhos (imagens, CSS, JS, JSON e links) são **relativos**, então o site funciona tanto na raiz quanto em subpastas, como é o caso do GitHub Pages. O GitHub Pages diferencia maiúsculas de minúsculas: mantenha os nomes dos arquivos exatamente iguais aos usados no código.
